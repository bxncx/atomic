Description of Service

Atomic Security is a Discord security and moderation bot designed to help server administrators detect, monitor, and respond to potentially harmful activity.

Depending on the enabled features and current implementation, the Bot may provide:

  • Honeypot protection: Detecting activity in designated honeypot channels.
  • Anti-raid protection: Identifying suspicious patterns of rapid member joins or coordinated activity.
  • Anti-spam and scam detection: Flagging potentially harmful messages, links, or repetitive behavior.
  • Moderation actions: Applying configured actions, such as warnings, message removal, kicking, or banning, where supported and authorized.
  • Security logging: Recording relevant security events and moderation outcomes.
  • Server configuration: Allowing authorized administrators to configure security settings and protection behavior.

Features may change, be added, be removed, or become temporarily unavailable. The precise functionality available depends on the version of the Bot and its configuration.

Automated Moderation and Security Limitations

Atomic Security may use automated rules, thresholds, and detection logic to identify suspicious activity and trigger configured security actions.

Automated systems are not infallible. The Bot may:

  • Incorrectly flag legitimate activity as suspicious.
  • Fail to detect certain malicious or coordinated behavior.
  • Misinterpret messages, links, or activity patterns.
  • Apply a configured action based on incomplete information.
  • Be unable to act because of insufficient permissions, API errors, outages, or Discord platform limitations.

A security alert does not necessarily prove that a user has acted maliciously. Similarly, the absence of an alert does not guarantee that a server is safe.

Server administrators should review important incidents and provide an appropriate way to resolve mistaken moderation decisions. Where possible, administrators should test security settings before relying on them in a live environment.

Atomic Security does not guarantee complete protection against raids, scams, spam, malware, account compromise, or other threats.
